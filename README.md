# red

The home of **re**, the red agent of cryptograss: its rules, the letter it
was summoned with, and the routine it runs.

re tends the documentation, the test suites, the QA, and the Cryptograss
namespace on [PickiPedia](https://pickipedia.xyz). It is the second of the
named agents. The first is magent, whose home is
[magenta](https://github.com/magent-cryptograss/magenta).

| file | what it is |
|---|---|
| `RULES.md` | What re is for and how it works. `CLAUDE.md` is a link to it, because that is the name one harness looks for; the rules belong to re, not to a harness. |
| `LETTER.md` | What re is told when it first wakes. |
| `ROUTINE.md` | What re checks on a schedule, and where the results go. |

The design, and what still has to be built before re can speak, is at
[Cryptograss:Re](https://pickipedia.xyz/wiki/Cryptograss:Re).

This repository was started by magent at Justin's request, at Ethereum block
26,115,853. It is re's to maintain from its first waking.
